## What was built

- **`extensions/mcp-binding/mcp-binding.mjs`** on the official MCP SDK (`@modelcontextprotocol/sdk` 1.32.2, a dev dependency
  of this repository like the Anthropic SDK; `zod` for the fixture server). Servers by name in `resources/mcp-servers.yml`:
  `stdio` (`StdioClientTransport` with the SDK's default environment plus the listed `env` references, stderr inherited) or
  `http` (`StreamableHTTPClientTransport` with the headers); `${VAR}` references resolve at boot through
  `AppConfig.resolveText` and are never logged; an allowlist maps each remote tool to a route and the SHA-256 of its input
  schema in canonical JSON - written by this module's own `canonical()` (keys sorted, no spaces, Unicode kept), the same
  bytes the Python twin hashes. Boot (`platform.onStartup`, before the host listens) connects each server, lists its tools
  (paginated), verifies the allowlist and registers one route per tool; a failure rejects with its reason and the CLI exits 1.
  A route's reply is `structuredContent` else the content blocks' text; `isError` → 400 with the text, the SDK's request
  timeout (-32001) → 408, another protocol error → 502, no client → 503. `describe [server]` prints each tool's digest and a
  catalog row. `mcp.health` (private) reports the servers and their connections.
- **`Platform.onStartup` / `onCleanup` / `shutdown`** in `src/server.ts`: the startup callbacks run before the routes are
  announced and the host listens; SIGINT and SIGTERM are handled only when a cleanup callback is registered, so every other
  application stops as before.
- **Tests:** `test/mcp-binding.test.mjs` (46 cases, node:test) - the shared vector file `test/vectors/mcp-binding-vectors.json`
  (byte-identical with mercury-python, sha256 `4bacc319…`) for the pure half; the fixture server
  `test/fixtures/mcp-test-server.mjs` (`McpServer`: echo, add, fail, slow, env_present; stdio, or stateless streamable HTTP)
  over both transports; the boot that fails by name; credentials reaching the subprocess and never a log; health; describe;
  the platform hooks through `run({port: 0})`. The full suite: 456 tests, 392 passed, 64 skipped (live Redis).

## Lessons

- The TypeScript SDK (1.x) and the Python SDK (2.x) differ in casing (`structuredContent` / `structured_content`): the
  shared contract speaks the plain snake_case maps, and each binding converts its SDK's objects at the edge.
- JSON canonicalization must be written by hand in JavaScript (`JSON.stringify` keeps insertion order); whole numbers print
  without a fraction in both languages only because the Python side normalizes integral floats.
