## Decisions

- The Mantle client, not the legacy `AnthropicBedrock`; the package imported lazily so the Claude API backend starts without it; the
  lock-file exemption rather than a bypass, because the next dependency bump would trip the guard again.
- One optional key, `llm.aws.region`; unset, the SDK's own resolution applies. No profile key: `AWS_PROFILE` is the chain's own.
- Two Bedrock surfaces behind one setting, `mantle` the default (Eric's ruling); the classic client's quiet region fallback is
  refused rather than inherited, so both surfaces and both packs answer a missing region the same way.
