## What was done

**The audit of a single call (`extensions/llm-helper/llm-helper.mjs`):** `llm.transcript.audit.single`, off by
default. With it and an audit store, a call without `tools` on `llm.chat` or `llm.stream` is recorded once the model
has answered and before the reply is judged: `singleRecord` builds a closed one-turn version 2 record, `saveSingle`
saves it under a new reference with the audit's grace and sends `{conversation, check: true}`; `transcriptAudit`,
`auditApply` and the sweep are untouched. The save is a promise the reply does not wait for; `auditSingleIdle` drains
it at shutdown; `auditBoot` stops the application by name when the switch is on and no working store is configured.

**Attachments:** the shape of the field in `llm-helper.mjs` (`attachmentsOf`, `attachmentOf`, `pagesOf`, checked in
`prepare` after the schema; a 400 on `llm.stream` and on a loop turn), and the reading in a new module beside it,
`extensions/llm-helper/attachments.mjs`: `resolveRoot`, the file inside the root (a relative path, the resolved path
inside it, no hidden entry, a regular file), the kind by the first bytes, the byte bound from the files' sizes, an
image's limit by backend (`imageMaxEncoded` on the backend objects), `pdfOf` (an encrypted or unreadable PDF refused,
the pages cut in the order named), the blocks and the references with the source file's SHA-256.

- **In a worker thread.** `loadInWorker` runs the reading in a worker of its own and brings a refusal back with its
  status. The Python twin uses a thread of its pool; here a hash, base64 and a PDF's cut would run on the one event
  loop that carries every call and every stream, whose token batches are pinned as never held back.
- **The deadline.** `withinDeadline` gives the caller its 408 at `params.timeout_ms` whatever the reading is doing,
  and `plan()` takes what the reading left as the SDK's abort signal; the SDK's own `timeout` option stays the
  request's, as the existing vectors pin it.
- `attachmentsBoot` stops the start when the configured root is not a folder.

**The PDF library.** `pdfjs-dist`, already a devDependency for the agent tools, only reads. Asked with three options
(`@cantoo/pdf-lib`, the maintained fork, MIT; `pdf-lib`, unchanged since 2022; no pages in this pack for now), the
maintainer chose **`@cantoo/pdf-lib`**. It is a devDependency, `^2.11.1`, loaded by name inside the worker; without
it a whole document goes as it is and `pages` is a 503 that names it. `npm install --save-dev` also moved `jose`
into alphabetical order in `package.json`.

**Shared files, byte for byte the Python pack's, their digests pinned:** `test/vectors/llm-audit-vectors.json` (25
cases), `test/vectors/llm-attachments-vectors.json` (48 cases) and the eight files of `test/fixtures/attachments`
(marked `-text` in `.gitattributes`). Every case passed without a change to a case, an expected row or a message: the
two helpers answer the same statuses and the same words.

**Tests:** the single-call section of `test/transcript-audit.test.mjs` (the vector run and six tests) and
`test/llm-attachments.test.mjs` (new: the vector run and seven tests; a cut PDF is checked by its pages' widths).

**Docs:** the helper's README - the sections "Attachments" and "The audit of a single call" are the Python README's
