## What was done

- **The same defect, by reading.** `ingestStatements` and `ENDPOINTS_QUERY` in
  `extensions/agent-tools/agent-tools.mjs` matched a relationship's ends by `key` without a label, as the Python
  twin did. A database index belongs to a label, so the database read every node for each end. The measurement is
  the Python pack's, which sent the same statements (its log 2026-11-27-205521): 150 relationships on Neo4j 5
