## Durable lesson

For npm publication triage, trust `registry.npmjs.org/<name>` over the website: search
indexing lags new packages by minutes, the package PAGE 403s curl (bot protection), and
a tombstoned name's history is only visible in the registry doc's `time.unpublished`
block. Follow-up (governance): the sole maintainer is a personal account — add org
co-maintainers when the npm org story is settled.
