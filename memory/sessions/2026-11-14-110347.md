**Title:** The MCP binding's bound routes become aliases of one `preload` function, `mcp.tool` (the Node.js twin of mercury-python #52)

## Context

Follows 2026-11-14-074701. In mercury-python, Eric asked which function serves `diagram.render.mcp`, found a closure made
by a factory, and had the binding refactored to the composable shape: one function declared with `@preload`, every bound
route its alias (mercury-python PR #52, merged 2026-11-14). He then asked for the same shape here, for consistency. A
generic MCP client - one route addressed by server and tool - was suggested and set aside on the way: ADR-0033 rejects it as
alternative (c), since the catalog cannot certify a target hidden in the call; the certifiable form would need a `headers`
map on the catalog row in both engines. One route per allowlisted tool stands.

## What changed (branch `refactor/mcp-binding-preload`)

- `extensions/mcp-binding/mcp-binding.mjs`: `createBinding` gains `tool(headers, body)`, declared at module level with
  `preload('mcp.tool', { instances: 10, isPrivate: true }, binding.tool)` beside `mcp.health`. It reads `getTrace()?.route`
  (the bus sets the executing service's route in the AsyncLocalStorage context for every execution, the pack's counterpart
  of the engines' read-only `my_route` header), resolves the server and the allowlisted tool through `bound(route)` (404
  for a route bound to none, `mcp.tool` itself included), checks that the body is a map (400) and calls the tool. `boot`
  fills `routes` (route to server and tool) and registers each allowlisted tool's route as an alias of `tool` with the
  server's `instances` - `registry.register(route, tool, { instances })`, the pack's counterpart of the engines'
  `Platform.register`; `shutdown` clears both maps. The `handler` factory is gone; `tool` and `routes` are returned for
  the tests.
- `test/mcp-binding.test.mjs`: the calls go through `PostOffice` local RPC on the test's registry, the path behind the
  HTTP host, so the alias dispatch and the route in the execution context are what the tests exercise; the first test pins
  the shape: every bound route's handler is `app.tool`, public, with the server's `instances` (3); `mcp.tool` is declared
  private in the default registry and a call to it is a 404.
- `extensions/mcp-binding/README.md` and the CHANGELOG's Unreleased entry describe the shape, as the Python twin's do.
